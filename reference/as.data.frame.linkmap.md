# Convert a linkmap to a data.frame Convert a linkmap back to a regular data.frame. Metadata is included.

Convert a linkmap to a data.frame Convert a linkmap back to a regular
data.frame. Metadata is included.

## Usage

``` r
# S3 method for class '`multifactor::linkmap`'
as.data.frame(x, row.names, optional, ...)
```

## Arguments

- x:

  a `linkmap` object.

- row.names, optional, ...:

  For compatibility, not currently used.

## Value

a `data.frame`
