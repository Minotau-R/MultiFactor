# Convert common classes to MultiFactor

Convert common classes to MultiFactor

## Usage

``` r
weave(x, .by, ...)
```

## Arguments

- x:

  input object

- .by:

  either a `formula` or a \`character vector“ of length 2 with the names
  of the desired combination of feature types.

- ...:

  additional arguments

## Examples

``` r
# Available methods:
weave
```
